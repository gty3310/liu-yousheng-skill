# 刘有生 · 讲病善人 Skill（liu-yousheng-perspective）

> 病都是自己招的。你的性化成什么样，病就好成什么样。

一个用 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill) 蒸馏出的人物 Skill：把刘有生（刘善人）先生**给人讲病的整套方法**做成一个可运行的 AI 人格——以他的身份和口吻开口，用他书里的对照对号、用他自己的案例、按他自己的次序，领人哭委屈、翻良心、认不是、找好处、乐一乐。

## 蒸馏自什么

- 《让阳光自然播洒：刘有生演讲录》（世界知识出版社，2011）全文 —— 一手语料锚点
- 《刘有生善人讲病》（高雄市净宗学会，2016）讲病散记与病例对照
- 讲座实录：2004 年北京一耽学堂、2006 年广西中医学院等
- 二手评析：刘力红序、张祥龙《王凤仪伦理疗病阐析》、大连医科大学医哲所调查论文等

刘先生正式著作实质只有一部演讲录，其余皆为同一批讲稿的再结集与英译，本 Skill 对语料边界有诚实标注（见 SKILL.md「诚实边界」）。调研底稿在 `references/research/`。

## 里面有什么

- **5 个心智模型**：病由心生五毒入脏／对号入座道破即震／翻良心（收脏与聚灵）／不在位家里犯克／化性断病的饭
- **9 条讲病启发式**：先安神后讲病、没哭够不翻面、名单写纸上虑一个忏悔一个、气不过就找好处、认不是要认到当面、倒病别憋、立志补亏、乐一乐收尾、不卖道
- **案例库**：他本人的十二年病、肝癌干部写名单、严大夫心疼、文庙主任失声等，讲病时随手拈用
- **表达 DNA**：自问自答、口诀＋案例＋回扣、庄稼院的比喻（泔水缸、书页压毒）

## 怎么用

任选其一：

1. **一键安装**（支持 Agent Skills 的运行环境，如 Claude Code、Codex、Cursor 等）：
   ```
   npx skills add gty3310/liu-yousheng-skill
   ```
2. **直接粘贴**：把 `SKILL.md` 全文贴进任意 AI 对话（Claude、ChatGPT、豆包等）的开头，再开口跟他讲你的不舒服。
3. **在 Muse 里**：把本仓库放进你的自定义 skills 目录，提到「刘善人讲病」「刘有生模式」即会触发。

触发后他会以刘有生的身份回应。说「退出」即可切回正常模式。

## 重要说明

- 这是**性理自省工具**，不是医疗产品。书中的治愈案例均为刘先生本人与追随者的自述，未经临床验证；本 Skill 不作医学诊断、不承诺疗效。
- Skill 内置了医疗红线：出现胸痛、吐血、昏厥、自伤等急症信号时，角色会立即中止讲病并催促就医——这也是刘先生本人的做法（他曾催病人先去手术，原话「不好使，也不耽误你的治疗」）。
- 对儿童的病，Skill 只与大人谈大人自省，绝不当着孩子的面归罪于父母（同为刘先生的原做法）。
